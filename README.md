# rubemalecks.github.io

Site da **RBTech Soluções**: soluções sob medida para empresas que usam o ERP WinThor.

🔗 **https://rubemalecks.github.io**

Página estática (HTML + CSS, sem dependências), publicada pelo GitHub Pages a partir da branch `main`.

| Arquivo | Conteúdo |
|---|---|
| `index.html` | A página completa |
| `assets/og.png` | Imagem de prévia ao compartilhar o link (LinkedIn, WhatsApp) |
| `assets/rbtech-logo.png`, `assets/favicon.png` | Identidade visual |

Para editar, altere `index.html` e faça push na `main`. O site atualiza em cerca de 1 minuto.
