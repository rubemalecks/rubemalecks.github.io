# rubemalecks.github.io

Portfólio de **Rubem Álecks**, fundador da **RBTech Soluções** (https://rbtech.app.br): RBConnect, Meu Assistente, RBCount
e rotinas para empresas que usam o ERP WinThor, com especialidade em campanhas e políticas de desconto.

🔗 **https://rubemalecks.github.io**

Página estática (HTML + CSS + um pouco de JavaScript para as telas do Meu Assistente se alternarem), publicada pelo GitHub Pages a
partir da branch `main`. Identidade visual da RBTech (azul do logo #0A7CCB, marinho só para texto e faixas, sem
amarelo; fontes Big Shoulders Display e Hanken Grotesk).

| Arquivo | Conteúdo |
|---|---|
| `index.html` | A página completa |
| `assets/og-rubem.png` | Prévia ao compartilhar o link (LinkedIn, WhatsApp) |
| `assets/connect-*.webp`, `assistente-*.webp`, `count-app.webp` | Telas dos produtos, com dados fictícios |
| `assets/rubem.jpg`, `assets/rbtech-logo-branco.png` | Foto e logo |

Regras de conteúdo: dos produtos privados, só os benefícios (nada de arquitetura, tabelas, provedor de IA ou
licenciamento); contato pelo LinkedIn; não citar formação acadêmica.

Para editar, altere `index.html` e faça push na `main`. O site atualiza em cerca de 1 minuto.
